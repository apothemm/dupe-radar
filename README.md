# DupeRadar

![CI](https://github.com/apothemm/dupe-radar/actions/workflows/ci.yml/badge.svg)

Python 3.11+. Поиск одинаковых файлов по размеру и SHA-256. Только отчёт, без удаления.

## Возможности

- Сначала группирует файлы по размеру, затем хеширует только кандидатов.
- Пропускает символические ссылки; ошибки доступа включаются в отчёт.
- Показывает группы дубликатов и потенциально освобождаемый объём.
- Потоковое чтение и атомарная запись JSON-отчёта.

## Запуск

```text
python dupe_radar.py ./folder --output report.json
python -m unittest discover -s tests -v
```

## Проверки

GitHub Actions выполняет сборку и тесты. Тесты находятся в исходниках репозитория и работают на временных данных.

## Ограничения

Файлы, меняющиеся во время чтения, исключаются. Изменение с тем же размером и временем модификации может остаться незамеченным; это отчёт, а не основание для автоматического удаления.

Предложения и ошибки — в Issues. Лицензия MIT.
